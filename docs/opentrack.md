# OpenTrack setup

1. Install the latest [OpenTrack release](https://github.com/opentrack/opentrack/releases).
2. Set **Input** to **UDP over network** and its port to `4242`.
3. Set **Output** to **freetrack 2.0 Enhanced** for DCS and ETS2, or the output required by the target game. MSFS commonly works through the TrackIR-compatible FreeTrack output.
4. Configure OpenTrack as desired.
5. Start the iPhone app, connect USB, start the bridge, then start OpenTrack.
6. Look straight ahead and press **Center** in the iPhone app or use OpenTrack's center hotkey and enjoy!
