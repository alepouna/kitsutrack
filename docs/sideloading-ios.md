# Sideloading on iOS

This guide isn't meant to teach you how to Sideload, but just how I've sideloaded the app my self. 

1. Download the IPA file from the [releases page](https://github.com/alepouna/kitsutrack/releases), we will come back to it in a moment
2. Setup [https://sidestore.io/]
3. Once that's ready, go to 'Apps' inside Sidestore and click the "Plus" on the top left
4. Find the IPA file you downloaded for KitsuTraack
5. Select and enjoy!


### If you can't get SideStore working but iLoader: 
1. Inside iLoader, click "Import IPA" and voila!

## I do not recommend using AltStore 

I've had issues with AltStore saying "this app has no ID" and signature related issues, especially with PAL so I recommend against it. SideStore works without a PC as well so its good.
